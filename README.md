# «Нейросеть как напарник» — мастер-класс для учителей школы

Статический сайт мастер-класса: как получать от нейросети готовые задания по своему предмету.
Live: https://freejam.online/inf/ — docroot `/var/www/inf`, симлинк `/var/www/freejam/inf`.

Аудитория — учителя-предметники (русский, литература, математика, история, обществознание,
физика, химия, биология, география, иностранный, окружающий мир, информатика).
Формат — 5 станций, 40 минут. Инструменты — GigaChat и Алиса AI.

## Стек
Чистый HTML + CSS + ES-модули, без сборки и зависимостей (как python-ege).
Python в браузере — Pyodide с CDN, только на странице тренажёра, в свёрнутом блоке
«если вы преподаёте информатику», и только по кнопке «Запустить».

## Файлы
- `index.html` — лендинг: герой с пишущей рукой, паспорт, маршрут пяти станций, модули, формула, манифест, FAQ.
- `workshop.html` — мастерская промпта: 5 блоков формулы, полный промпт, два шаблона, чек-лист, таблица плохо/хорошо.
- `simulator.html` — три шага: конструктор промпта по предмету (шаг 1) → песочница Python для информатики (шаг 2, свёрнута) → «записка от руки» как бонус (шаг 3).
- `debug-lab.html` — лаборатория проверки: задание, написанное нейросетью, разбор по фрагментам (фактическая, терминологическая, методическая ошибка, несоразмерность), два промпта, мини-тест.
- `bank-tasks.html` — копилка заданий по предметам: фильтры по предмету/классу/теме, эталонные ответы и критерии, добавление своих (localStorage).
- `assets/hand.js` — движок «руки»: обратная кинематика, сцена героя, запись текста, ревилы, тема, меню.
- `assets/inf.css` — дизайн-система (бумага, карточки, рукописный шрифт, тёмная тема).
- `assets/tool.js` — данные предметов, тем и контекстов, сборка промпта, песочница Pyodide, композер записки.
- `assets/hl.js` — подсветка синтаксиса Python в песочнице: оверлей под прозрачной textarea
  (источник правды — сама textarea), синхронизация прокрутки через transform.
- `assets/debug.js` (лаборатория проверки), `assets/tasks.js` (копилка) — данные и логика страниц.
- `assets/fonts/caveat-*.woff2` — рукописный шрифт Caveat (OFL), локально, кириллица + латиница.
- `_attic/v1-stack/` — прежние версии сайта (в т.ч. «технократичный» дизайн и вариант под площадку МУМО) вместе с md-исходниками.

## Дизайн
Основа — шаблон 21st.dev «Handwritten Notes Landing Page» (автор kedhareswer, свободный).
Оттуда взяты: язык «бумага + линейная графика + рука-плоттер», палитра (терракота + бирюза),
кинематика руки (два звена, IK), композиция конверта с письмом, бейджи, кнопки-капс, пунктирные трассы.

Почему рука пишет шрифтом, а не штрихами: в шаблоне штриховые данные Hershey есть только для латиницы.
Для русских текстов рука ведёт по строке, а буквы проявляются под пером (clip-path по тексту Caveat),
с покачиванием по базовой линии и подъёмом пера между строками.

## Как править
- Текст героя (записка на листе) — массив `paras` в `index.html`, блок `writeScene({...})`.
- Сцена героя (конверт, письмо, штамп) — переменная `paper` и `geo` в том же блоке.
- Предметы, темы, контексты и уровни промпта — константы `SUBJECTS`, `CONTEXTS`, `LEVELS` в `assets/tool.js`.
- Записка в тренажёре — `NOTE_*` и `initComposer()` в `assets/tool.js`.
- Копилка — массив `TASKS` в `assets/tasks.js`; фильтры берут предмет и тему из данных автоматически.
- Цвета, шрифты, отступы — переменные в начале `assets/inf.css`, правки контраста — в конце файла.

## Грабли
- Вертикаль записки — `box.y` (базовая линия первой строки), шаг строк — `size * lead`.
  Печатная шапка листа «ДЛЯ УЧИТЕЛЕЙ ШКОЛЫ» занимает y ≈ −145…−131, поэтому `box.y = -104`
  (первая строка тогда начинается с −125 и между шапкой и почерком остаётся зазор).
- Строки с `align: "right"` пишутся слева направо от `startX = box.x + box.width − w`;
  и клип, и позиция пера считаются от `startX`. Если считать клип от левого края блока,
  перо ведёт по пустому листу, а подпись остаётся невидимой.
- Песочница живёт в `<details>`: подсветка инициализируется в скрытом блоке, поэтому на `toggle`
  надо переслать событие `input` в textarea, иначе слой подсветки может не пересчитаться.
- Любая правка `inf.css`, `hand.js`, `hl.js`, `tool.js`, `debug.js`, `tasks.js` — поднимать `?v=N`
  на всех пяти страницах, иначе браузер держит старый файл.
