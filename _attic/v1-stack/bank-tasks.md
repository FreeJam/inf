### ❄️ Задача 1. «Маршрут ледокола "Ямал"»
* **Тема ФГОС:** Алгоритм с ветвлением (`if-else`).
* **Класс:** 7–8.
* **Сюжет:** Ледокол пробивает торосы разной толщины.

#### Условие:
Напишите программу, которая принимает на вход толщину льда в метрах ($h$). Если $h \le 1.5$, ледокол идет со скоростью 15 узлов (`"Обычный ход"`). Если $1.5 < h \le 3.0$, скорость снижается до 7 узлов (`"Усиленный ход"`). Если $h > 3.0$, требуется помощь второго судна (`"Запрос поддержки"`).

```python
# Эталонное решение
h = float(input("Введите толщину льда (м): "))
if h <= 1.5:
    print("Обычный ход (15 узлов)")
elif h <= 3.0:
    print("Усиленный ход (7 узлов)")
else:
    print("Запрос поддержки второго ледокола")
```

### 🏛️ Задача 2. «Расфрахтовка БЭСМ-6»
* **Тема ФГОС:** Двумерные массивы и статистика.
* **Класс:** 9–11.
* **Сюжет:** Вычисление быстродействия советских суперкомпьютеров.

#### Условие:
Дан массив производительности процессоров ЭВМ С.А. Лебедева (в тысячах операций в секунду). Найдите средний прирост мощности между поколениями машин.

```python
# Данные (МЭСМ, БЭСМ-1, БЭСМ-2, БЭСМ-6)
performance = [3, 10, 100, 1000] # в тыс. оп/сек

gains = [performance[i] / performance[i-1] for i in range(1, len(performance))]
print(f"Средний прирост производительности в поколениях: {sum(gains)/len(gains):.2f}x")
```
