Лаборатория: ИИ как педагогический наставник

Главная цель — научить ИИ не выдавать готовый ответ, а наводить ученика на мысль через педагогический диалог.

Кейс

«Сломанный» код ученика 8 класса

Задача: посчитать количество букв «Э» в историческом документе. Нажмите на строку, чтобы увидеть разбор ошибки.

student.pyкликните на строку 
# Ошибка ученика: бесконечный цикл и выход за границы
text = "Первая ЭВМ МЭСМ была создана в 1950 году"
i = 0
count = 0

while i <= len(text):
    if text[i] == "Э":
        count += 1
    # Забыл добавить i += 1 !

print("Количество букв Э:", count)

🤖 Запрос к ИИ: роль-плей «этичный наставник»

Ключевая часть — запрет на готовый ответ.

Ты — доброжелательный и мудрый учитель информатики.
Посмотри на код ученика выше. Ученик не понимает,
почему программа зависает.

НЕ ДАВАЙ ему готовый код и не называй ошибку напрямую.
Сформулируй 2 наводящих вопроса, которые помогут ему
самому заметить отсутствие изменения счётчика цикла 'i'.
Педагогический эффект: ученик, который сам нашёл ошибку, запоминает её причину. Ученик, которому показали исправленный код, запоминает только факт подсказки.
