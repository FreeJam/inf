## ❌ Пример «Сломанного» кода ученика

Ученик 8 класса пытался написать программу для подсчета символов в историческом документе, но допустил ошибку:

```python
# Ошибка ученика: Бесконечный цикл и выход за границы
text = "Первая ЭВМ МЭСМ была создана в 1950 году"
i = 0
count = 0

while i <= len(text):
    if text[i] == "Э":
        count += 1
    # Забыл добавить i += 1 !
    
print("Количество букв Э:", count)
```

## 🤖 Запрос к ИИ для роль-плея «Этичный наставник»

```text
Ты — доброжелательный и мудрый учитель информатики. 
Посмотри на код ученика выше. Ученик не понимает, почему программа зависает.
НЕ ДАВАЙ ему готовый код и не называй ошибку напрямую. 
Сформулируй 2 наводящих вопроса, которые помогут ему заметить отсутствие изменения счетчика цикла 'i'.
```
