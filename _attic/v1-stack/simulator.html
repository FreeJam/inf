Виртуальный тренажёр: ИИ-конструктор задач

Отработка навыка постановки задачи: соберите промпт из четырёх параметров, а затем проверьте код, который вернёт нейросеть, прямо в браузере.

🎛️ Шаг 1 · Параметры задания

Каждый параметр — часть формулы промпта. Меняйте и сравнивайте результат.

Профильный: ученик пишет код с нуля по условию.

// Нажмите «Сгенерировать промпт», чтобы собрать запрос

Проверка результата: вставьте ответ нейросети в песочницу ниже. Эталонное решение, которое не проходит собственные тесты, — плохая задача. Так вы ловите «галлюцинации» до урока.
Шаг 2 · Проверка кода

Онлайн-песочница Python

Код исполняется локально в браузере (Pyodide, WebAssembly) — ничего не уходит на сервер. Первый запуск подгружает окружение (~10 МБ), дальше работает мгновенно.

Код задачи

Пример: поиск минимума в массиве температур по станциям Ямала.

Функция input() в браузерной песочнице не поддерживается — задавайте данные прямо в коде или через sys.stdin.

Что проверять в сгенерированной задаче

  • Решение проходит собственные тест-кейсы автора.
  • Граничные случаи: пустой массив, один элемент, отрицательные значения.
  • Историческая справка не содержит выдуманных дат и фамилий.
  • Условие однозначно: нет «примерно», «около», «примерно столько».
