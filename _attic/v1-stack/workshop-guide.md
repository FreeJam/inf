# 🛠️ Руководство по промпт-инжинирингу для учителя информатики

Воспользуйтесь готовой конструкцией запроса для создания задач, интегрирующих традиции, историю и программирование.

---

## 📐 Формула «Контекстного Промпта»

$$ 	ext{Промпт} = 	ext{Роль} + 	ext{Тема по ФГОС} + 	ext{Историко-культурный контекст} + 	ext{Требования к коду} + 	ext{Формат вывода} $$

### Компоненты формулы:

1. **Роль:** `Выступи в роли методиста по информатике и эксперта по историческому просвещению.`
2. **Тема ФГОС:** `Тема: Алгоритмы обработки массивов и поиск максимума на Python.`
3. **Контекст:** `Сюжет: Статистика освоения Северного морского пути и подвиги ледокольного флота Ямала.`
4. **Требования:** `Код должен содержать комментарии на русском языке. Использовать понятные переменные.`
5. **Формат:** `Выведи: Условие задачи, Входные/Выходные данные, Решение, 3 тест-кейса.`

---

## ⚡ Готовые конструкции промптов

### Шаблон 1: Генератор краеведческих задач
```text
Выступи в роли эксперта-методиста. Составь задачу по программированию на Python на тему [УКАЖИТЕ ТЕМУ, например: Цикл WHILE]. 
Сюжет задачи основывается на истории [УКАЖИТЕ СОБЫТИЕ, например: Строительство 501-й стройки / Маршруты экспедиции Ямал].
Добавь в условие краткую историческую справку (2-3 предложения).
Сгенерируй эталонное решение и 3 набора входных/выходных данных.
```

### Шаблон 2: Трехуровневая адаптация
```text
Возьми предыдущую задачу и сформируй 3 уровня сложности:
1. Базовый (Fill-in-the-blank): Ученик заполняет пропуски в коде.
2. Профильный: Ученик пишет код с нуля.
3. Олимпиадный: Добавь ограничение по памяти и обработку исключений (try-except).
```
