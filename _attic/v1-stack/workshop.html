Руководство по промпт-инжинирингу

Готовая конструкция запроса для создания задач, соединяющих традиции, историю и программирование.

Этап 01

Формула «контекстного промпта»

Промпт =
+
Роль кто ты
+
Тема по ФГОС что тренируем
+
Историко-культурный контекст о чём сюжет
+
Требования к коду как писать
+
Формат вывода что получить

1 · Роль

Нейросеть отвечает тем лучше, чем точнее задана позиция эксперта.

Выступи в роли методиста по информатике
и эксперта по историческому просвещению.

2 · Тема по ФГОС

Привязка к рабочей программе — иначе получим «задачу вообще».

Тема: алгоритмы обработки массивов
и поиск максимума на Python.

3 · Контекст

Историко-краеведческий сюжет — то, что делает задачу воспитательной.

Сюжет: статистика освоения Северного морского пути
и подвиги ледокольного флота Ямала.

4 · Требования

Комментарии на русском, понятные имена переменных, без «магии».

Код должен содержать комментарии на русском языке.
Использовать понятные переменные. Без внешних библиотек.

5 · Формат

Фиксируйте структуру ответа — так его не нужно переписывать.

Выведи: условие задачи, входные/выходные данные,
эталонное решение, 3 тест-кейса.

⚠️ Чего избегать

Типичные ошибки, из-за которых ответ приходится переделывать.

«Придумай задачу по Python» — нет темы, нет контекста, нет формата: получим случайный текст.
«Сделай красиво» — оценочное требование, нейросеть его не может проверить.
Готовые конструкции

Шаблон 1 · Генератор краеведческих задач

Замените два поля в квадратных скобках — получите задачу под свой класс и тему.

Текст промпта
Выступи в роли эксперта-методиста. Составь задачу по программированию
на Python на тему [УКАЖИТЕ ТЕМУ, например: Цикл WHILE].

Сюжет задачи основывается на истории
[УКАЖИТЕ СОБЫТИЕ, например: маршруты экспедиции Ямал].

Добавь в условие краткую историческую справку (2–3 предложения).
Сгенерируй эталонное решение и 3 набора входных/выходных данных.
Комментарии в коде — на русском языке.
Шаблон 2 · Трехуровневая адаптация
Возьми предыдущую задачу и сформируй 3 уровня сложности:

1. Базовый (fill-in-the-blank): ученик заполняет пропуски в коде.
2. Профильный: ученик пишет код с нуля по условию.
3. Олимпиадный: добавь ограничение по памяти, обработку
   исключений (try-except) и нестандартные входные данные.

Для каждого уровня укажи: цель по ФГОС, критерии оценивания,
5 тест-кейсов (включая граничные).
Практика

Плохой и хороший промпт: разница

ПлохоХорошо
«Дай задачу по циклам» «Тема: цикл while, 8 класс ФГОС. Сюжет: подсчёт дней работы полярной станции на Ямале. Нужны условие, решение, 3 теста.»
«Проверь код ученика» «Не называй ошибку прямо. Задай 2 наводящих вопроса, чтобы ученик сам увидел отсутствие i += 1.»
«Сделай тест по истории ЭВМ» «10 вопросов с 4 вариантами по машинам С. А. Лебедева (МЭСМ → БЭСМ-6), с ответами и пояснениями, уровень 9 класса.»
Правило площадки: любой сгенерированный материал проходит педагогическую экспертизу. Нейросеть предлагает — учитель проверяет факты, даты и корректность эталонного решения.
